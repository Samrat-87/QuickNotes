## Why QuickNotes

QuickNotes is a clean, minimal note-taking app built for speed. It stores everything locally, works offline, and makes writing frictionless with a focused editor and quick actions.

## Features

1. Create, edit, and delete notes instantly.
2. Offline-first storage with AsyncStorage.
3. Clean, distraction-free writing experience.

## Getting Started

```bash
npm install
```

```bash
npm start
```

Other options:

```bash
npm run android
npm run ios
npm run web
```
